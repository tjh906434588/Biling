# 番茄小说题材族约束库（通用 · 由样本小说总结校准）

> 目的：把任意番茄小说的**前十章正文**总结成「题材族约束」——与题材挂钩、可直接填入
> `backend/app/agents/platform_rules.py` 的 `GENRE_FAMILY_REGISTRY`（storytelling 结构性叙事 + rhythm 开篇/金手指兑现节奏）。
> 本库为**通用题材族库**：以巅峰榜 30 部起步，后续可随时追加新手榜、书库前 N 页、指定单本等任意样本，
> 新样本一律 **归族 → 逐本提取 → 同族多本比对融合** 进对应题材族，不另起炉灶、不重复建库。
> 数据来源：番茄小说正文（经字库反爬 ddddocr 解码还原，映射见 `../font/mapping_ocr.json`）。
> 章节语料：`../corpus/<书名>/dec_ch{1..10}.txt`（样本为本地临时文件，**提炼完即删除，不入库**，见 `../README.md`「语料清理」）。

---

## 新增一批小说的处理流程

1. **抓取**：用 `extract_template.js`（或既有浏览器抓取链路）抓取目标书前十章 → 写 `../corpus/<书名>/raw_ch{1..10}.txt`。
2. **解码**：`python ../batch_decode.py <书名>` → 生成 `dec_ch{1..10}.txt`（已有 dec 则跳过）。
3. **归类**：按背景 × 题材判断本书属于哪个题材族（mystery / urban_high_wu / strong_flow / romance / gaming / historical / realistic_career / 其他）。
4. **逐本提取**：阅读前十章，按本文件"逐本观察记录"的模板，在本节末尾追加该书观察（开篇 / 金手指兑现 / 事件组织 / 钩子等）。
5. **比对融合**：若目标族已有 ≥2 本样本 → 跨本重合项并入【必写】，仅个别本出现的写法并入【可选】；若族内仅 1 本 → 标注【参考规律】待验证。
6. **注入**：将融合结果同步到 `platform_rules.py` 对应族的 `GENRE_STORYTELLING_*` / `GENRE_RHYTHM_*`。
7. **自检**：跑冒烟脚本确认注入命中 / 未命中 / 分级标注齐全，无语法错误。

### 逐本观察记录模板（字段固定，缺失的写"无"）

```markdown
### 《书名》（<题材族>样本）

- **题材**：<题材 × 金手指/背景一句话>
- **章长**：约 <数字> 字/章（或注明异常）
- **开篇黄金三章**：逐章列第1/2/3章干什么、章末钩子、金手指何时点名
- **金手指兑现**：点名（第几章）→ 展威（第几章）→ 后续节奏（有条件/代价/反噬？）
- **事件组织**：每章"推进 + 章末钩子"的结构；对话占比；群像区分手法
- **悬念管理**：表层悬念 + 底层悬念，何时埋线、何时引爆
```

### 分级口径（题材族节内使用）

- 【必写】：族内 ≥2 本重合的结构/节奏项；
- 【可选】：仅个别本出现的写法；
- 【参考规律】：族内仅 1 本样本，待更多样本验证。
- 样本增多后动态升档：本数够了就把【参考规律】/【可选】升为【必写】。

### 平台常见标签 ↔ 题材族对照（第 3 步「归类」用）

番茄平台标签命名较碎，先按语义归到题材族，再决定是否新建：

| 番茄常见标签 | 归入题材族（key：label） |
|---|---|
| 都市 / 职场 / 教育 / 创业 / 现实 | `realistic_career`：现实事业流（background=realistic） |
| 玄幻 / 仙侠 / 奇幻 / 西幻 / 武侠 / 异能 | `strong_flow`：强爽流 |
| 都市 ×（异能 / 高武） | `urban_high_wu`：都市高武流（background=alternate 半架空） |
| 悬疑 / 推理 / 灵异 | `mystery`：悬疑推理流 |
| 言情 / 甜宠 | `romance`：言情甜宠流 |
| 科幻 | `sci_fi`：科幻流 |
| 历史 | `historical`：历史权谋流 |
| 军事 | `military`：军事流 |
| 游戏 | `gaming`：游戏流 |
| 同人 | `fanfic`：同人流 |
| 校园 | `campus`：校园成长流 |

**常见同义变体**（归类时按标准标签看待）：修仙/修真→仙侠，魔幻→奇幻，末世/末日→科幻，
上班流/打工人→职场，甜文/宠文→甜宠，现言/古言/古代言情→言情，电竞/游戏竞技→游戏，
规则怪谈→悬疑，恐怖/惊悚→灵异。
> 运行时同义归一以 `backend/app/agents/platform_rules.py` 的 `GENRE_ALIASES` 为代码事实源
> （前端 `frontend/src/constants/meta.ts` 同义提示与之同步），本表为文档镜像，改动须两端同步。

### 悬疑推理流（mystery：悬疑 / 推理 / 灵异）

- **校准样本（6 本）**：《十日终焉》+《北派盗墓笔记》《规则怪谈》《诡舍》《我以狐仙镇百鬼》《死亡游戏》（语料 `../corpus/<书名>/`）
- **样本题材画像**：谜题/怪谈/死亡驱动——死亡游戏（无限流）、盗墓行当、规则怪谈回档、副本解密、民俗志怪、狼人杀博弈

#### storytelling 结构性叙事约束（对应 `GENRE_STORYTELLING_MYSTERY`）

> 【题材特化·悬疑推理流（平台签约标准的题材分支，仅本书适用）】本书是谜题/怪谈/死亡驱动型题材（悬疑/推理/灵异：死亡游戏、密室困局、案件谜团、规则怪谈、民俗志怪等），以下规则是平台签约标准按题材激活的分支条款（与通用条款同级、同属系统级；与通用平台条款在**开篇方式/金手指兑现节奏/事件结构**上冲突时，一律以本段为准，通用条款相应让位），只对本类题材成立，写作时遵循：
>
> **【必写】**（6 本高分样本全部重合，本族核心规律）
> - **开局即异常**：第 1 章内必须完成"异常处境 + 核心设定 + 首次死亡/危机"三件套（死亡现场/密闭空间/诡异事件/规则发布/主角身陷绝境），拒绝平铺直叙的开篇，先抛钩子再补背景；
> - **规则/提示即玩法**：核心规则、预言或提示文本（游戏规则/怪谈规矩/应劫预言/谜题条件）是驱动读者期待的叙事装置，由角色台词或现场证据宣布、一经确立为绝对事实源；读者抱着"哪条规则会应验"的预期追读，反转不得推翻已确立规则除非先给新证据；
> - **章末钩子制度化**：每章结尾必须停在悬念/危机/新信息/倒计时上（声音逼近/身份反转/下个预告/谜底一角），极少平收；强钩子=事件性悬念，弱钩子=情绪余韵，禁止"想明白/入睡"式收尾；
> - **主角异于常人+强信息差**：主角必有超出常人的一技（回档记忆/冷静推理/隐藏身份/表演伪装/行内眼力），且让"读者知道而书中角色不知道"的信息差成立——这是本族核心爽点；
> - **恐怖+吐槽双声道**：死亡/恐怖/危机密集推进的同时，必须配一个喜剧调剂位（主角吐槽/憨憨配角/荒诞比喻）解压，避免全书纯压抑；
> - **单章短小单事件**：每章 2000-3000 字、只推一个场景/事件，章节间连续推进不断章，适合移动端碎片阅读。
>
> **【可选】**（写法之一，出现于 1-2 本，可写可不写）
> - **叙事视角**：第一人称讲述体（回忆录/评书口吻，可事后诸葛、可自由剧透）或第三人称限知（读者信息量≈主角，贴脸营造恐惧）皆可；
> - **时间结构**：死亡回档循环（同一场景反复重走、每次升级）/副本关卡制（倒计时任务）/单局游戏制（日程+会议）/线性成长（逐年应劫）/回忆倒叙（现实线+过去线双轨）皆可；
> - **爽点机制**：推理碾压/心理博弈/系统任务打怪/靠山流（隐藏大佬被保）/行内揭秘发财，按题材自选一种为主；
> - **恐怖浓度**：血腥直给或氛围悬念皆可，但都得配"规则感"（恐惧有来源、有规律，非纯吓人）；
> - **开篇风格**：日常突转（温情世界撕开一角）/场景氛围（雾夜大巴）/强冲突反转（告白变枪杀）皆可。

#### rhythm 开篇/金手指兑现节奏约束（对应 `GENRE_RHYTHM_MYSTERY`）

> 【开篇与金手指兑现·悬疑推理流】本书为谜题/怪谈/死亡驱动型题材（悬疑/推理/灵异），开篇与金手指兑现遵循以下节奏（**与上文通用平台条款冲突时以此段为准**，通用条款相应让位）：
>
> **【必写】**
> - **黄金开篇**：第 1 章直接进入"异常处境"（密闭空间/死亡现场/诡异事件/规则发布），前 300 字内建立悬念与危机；允许"主角一睁眼已身陷绝境/已死过一次"式的无铺垫开场（本类题材通用开篇），最迟第 1 章内抛出核心谜题、规则或设定，禁止用日常/身世/校园铺垫开场；
> - **核心能力点名**：主角的特殊设定（回档/推理/隐藏身份/金手指）第 1 章内点名，第 1-3 章内必须出现首次危机或死亡事件立住题材基调；
> - **情绪出口**：本类题材的爽点 = 识破/揭底反转/破局瞬间/信息差碾压；受挫与被误导是常态，情绪出口落在"主角识破对方/真相大白/抢跑预知"的智力高潮上，不套用打脸模板安排反击；
> - **钩子密度**：揭底后必须立刻埋入下一层悬念，防止"谜底揭晓=故事泄气"。
>
> **【可选】**
> - **兑现速度**：读档/预知型金手指可快速展威（第 1-2 章就靠记忆抢跑）；纯悬疑蓄力型可慢热（第 1-3 章只露小聪明/铺垫氛围，大揭底放单元或卷末）；
> - **开篇写法**：血腥冲突开场（第一章见血）或氛围悬念开场（先立世界观再引事件）或日常突转开场（先写温馨再撕开异常）皆可。

### 都市高武流（urban_high_wu：都市 / 异能 / 高武，background=alternate 半架空）

- **校准样本（8 本）**：《我不是戏神》+《大一实习749》《我在精神病院学斩神》《时停起手》《天物觉醒》《我操作的少女》《诸神愚戏》《异兽迷城》（语料 `../corpus/<书名>/`）
- **样本题材画像**：现代都市为表世界 + 超凡力量为里世界（灰界/灾厄/执法者/怪物收容/觉醒学院/信仰游戏/都市兽群）；主角多为穿越/玩家身份（认知差开局）、网感口语文风、金手指快速兑现、围观震惊回路、章末强钩子

#### storytelling 结构性叙事约束（对应 `GENRE_STORYTELLING_URBAN_HIGH_WU`）

> 【题材特化·都市高武流（平台签约标准的题材分支，仅本书适用）】本书是现代都市背景下的超凡力量题材（都市高武：异能觉醒/超凡者/官方与民间超凡机构/都市怪谈/末世废土超凡等），现实都市框架与超凡力量体系并存，以下规则是平台签约标准按题材激活的分支条款（与通用条款同级、同属系统级；与通用平台条款在**开篇方式/金手指兑现节奏/事件结构**上冲突时，一律以本段为准，通用条款相应让位），只对本类题材成立，写作时遵循：
>
> **【必写】**（8 本高分样本高度重合，本族核心规律）
> - **双层世界**：现实都市是表世界（学校/公司/街道/夜市/出租屋），超凡力量是里世界（觉醒者/异常事件/超凡机构/灾厄/怪物），两界交汇处是冲突主场；表层冲突（当前任务/事件/麻烦）推进时同步埋里世界真相的线索，禁止只写表世界打架、里世界沦为背景板；
> - **身份差开局**：主角通常是穿越/玩家/异界来客，与世界存在身份差与认知差（知道剧情/规则/面板而土著不知），这是本族最大公约数，也是信息差爽点的来源；
> - **网感文风**：口语化+网络梗（短句、心理吐槽、感叹号），贴近年轻读者语言，避免文绉绉书面腔；
> - **装逼→震惊回路**：主角展威/狠人做派后必有旁观者集体震惊/叹服的反馈镜头（"主角装逼→围观者震撼"是本族最稳定的爽点回路），且主角装逼要建立在自身能力与底牌之上，禁止无脑硬刚权威；
> - **能力有代价**：主角的超凡能力/金手指必须交代获得方式与限制条件（每天 1 分钟/表演才有效/使用次数/能力反噬/发动条件），能力的强与弱、能用与不能用都清清楚楚，禁止无代价无限制的万能外挂；
> - **章末强钩子**：每章末尾落一个"异常入侵日常"或"真相露出缝"或"事件升级"的钩子（新的异常出现/身份疑点/组织动作/倒计时），禁止平收；
> - **喜剧调剂**：恐怖/紧张/杀伐的推进中安排喜剧桥段（嘴炮、装疯、穷鬼梗、日常互动）调剂节奏。
>
> **【可选】**（写法之一，出现于个别几本，可写可不写）
> - **世界观骨架**：末世废土（赌命局/收容）/学院觉醒（高考式觉醒日）/游戏副本（玩家魂穿）/诸神信仰游戏（克系猎奇）/都市兽群（悬疑惊悚）皆可，按题材自选；
> - **开局方式**：概述铺设定（人设+动机+金手指期待）/场景+路人对话切入/内心独白+冲突现场/倒叙高潮开局/体内对话切入/纯诡异场景/日常突转，皆可；
> - **金手指形态**：系统面板/规则系有限能力（时间静止）/收容能力/卡牌/回档/谎言感知，按题材自选；
> - **爽点重心**：装逼打脸主导 or 悬疑惊悚主导（如异兽迷城：前 2 章主角无金手指纯靠悬念撑）or 猎奇黑色幽默主导（如诸神愚戏）皆可；
> - **体制维度**：主角加入官方/组织（749 局/执法者）或游离于体制外皆可。

#### rhythm 开篇/金手指兑现节奏约束（对应 `GENRE_RHYTHM_URBAN_HIGH_WU`）

> 【开篇与金手指兑现·都市高武流】本书为现代都市背景下的超凡力量题材（都市高武），开篇与金手指兑现遵循以下节奏（**与上文通用平台条款冲突时以此段为准**，通用条款相应让位）：
>
> **【必写】**
> - **黄金开篇**：第 1 章直接进入"超凡异常"（异象降临/穿越失忆/能力觉醒/异常事件目击），前 300 字建立超凡悬念与危机；允许"一睁眼身处异境/失忆开局"式无铺垫开场；最迟第 1 章内点名核心金手指/能力与主线矛盾，日常只能作为表世界背景穿插，禁止纯校园/职场日常铺垫开场；
> - **金手指点名**：主角的超凡能力/金手指第 1 章内"点名"（获得/觉醒/穿越自带），能力代价/限制要在首次使用时就让读者看到（用能力的后果、条件、反噬），避免无代价外挂；
> - **首次展威**：第 1-4 章内至少"小展威"一次（当众或独自用出效果，受限于当前能力等级与代价，不必打大怪），让读者吃到第一口爽点；大展威/身份反转放在攒足底牌与限制解除之后；
> - **情绪出口**：本类题材的爽点 = 当众展威/信息差反杀/破解异常事件；主角受挫或身份被轻视后尽快安排符合当前能力的小反击（借用能力规则、机构权限、队友配合），不憋长线。
>
> **【可选】**
> - **展威节奏**：可快可慢——快节奏（第 1-2 章即兑现，如我操作的少女 ch1 夺舍秒杀）或慢热蓄力（如斩神 ch10 才首杀、天物觉醒 ch10 才揭寰级能力），按剧情需要；慢热型要靠悬念/日常反差/世界观信息撑住前几章，避免干等；
